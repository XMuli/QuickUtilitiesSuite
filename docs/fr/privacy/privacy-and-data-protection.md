# Confidentialité et protection des données

- Pour la traduction d'images ou l'OCR, les captures d'écran sont envoyées à des API tierces pour obtenir les résultats ; l'utilisation de ces fonctionnalités implique l'acceptation de leurs conditions. Ces fonctionnalités nécessitent un accès à Internet.
- Les autres fonctionnalités s'exécutent localement, ne nécessitent aucune autorisation réseau et conservent les données sur votre appareil.

Politiques de confidentialité des fournisseurs d'API :
- Youdao API : https://fanyi.youdao.com/openapi

## OCR (Extraction de texte depuis des images)

## Interrupteur Defender
Activez ou désactivez rapidement Microsoft Defender Antivirus (exécuter en tant qu'administrateur).
**Modes**
- Arrêter : Defender désactivé ; aucune analyse.
- Démarrer : Windows gère Defender ; si un autre antivirus est présent, Defender est désactivé.
- Activer : Defender s'exécute indépendamment des autres antivirus.

# Privacidad y protección de datos

- Para la traducción de imágenes u OCR, las capturas de pantalla se envían a APIs de terceros para obtener resultados; el uso de estas funciones implica la aceptación de sus términos. Estas funciones requieren acceso a Internet.
- Las demás funciones se ejecutan localmente, no necesitan permisos de red y mantienen los datos en su dispositivo.

### Больше контроля для опытных пользователей

Нужно временно отключить Windows Defender для определённых задач? Quick DefenderToggle позволяет быстро включить или отключить встроенный Microsoft Defender Antivirus — идеально для разработки ПО, отладки системы и других сценариев, где необходима временная приостановка защиты в реальном времени.

### Основные возможности

**Три режима управления**
- STOP: Полная остановка Defender
- START: Запуск Defender (Windows управляет автоматически)
- FORCE ENABLE: Принудительное включение Defender

**Обратная связь о состоянии в реальном времени**
Чёткое отображение текущего статуса Defender — результат каждого действия виден сразу.

**Подробные логи операций**
Фиксация каждого шага для удобного отслеживания и устранения неполадок.

---

### Почему стоит выбрать Quick DefenderToggle

**Быстрее ручных методов**
Не нужно разбираться с редактором групповых политик или реестра — задача решается одним кликом.

**Более безопасная операция**
Использует стандартные механизмы групповых политик для управления Defender без повреждения системных настроек.

**Чёткое отображение статуса**
Обновление статуса в реальном времени исключает неопределённость: активен Defender или отключён.

### Сценарии использования

**Разработчики ПО**
Временное отключение Defender при разработке или тестировании для предотвращения ложных срабатываний.

**Системные администраторы**
Временная приостановка защиты при массовом развёртывании ПО или настройке системы для повышения эффективности.

**Опытные пользователи**
Отключение защиты для оптимизации системы, очистки или специализированных операций.

---

### Начало работы

1. **Запуск от имени администратора**
   Кликните правой кнопкой мыши по программе и выберите «Запуск от имени администратора»

2. **Выберите действие**
   Выберите STOP, START или FORCE ENABLE

3. **Выполните операцию**
   Нажмите «Выполнить» и просмотрите результат операции и статус

---

### Важное уведомление

> **Предупреждение безопасности**
> Отключение Windows Defender снижает уровень безопасности системы. Используйте этот инструмент только при необходимости и повторно включите защиту сразу после завершения задачи.

> **Требуются права администратора**
> Для работы этого инструмента необходимы права администратора.

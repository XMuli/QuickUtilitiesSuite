# Конфиденциальность и защита данных

**Последнее обновление:** март 2026
**Разработчик:** Wengeng Zhang (xmulitech@gmail.com)

## Обзор

QuickUtilitiesSuite разработан с учётом конфиденциальности. Большинство функций работают полностью автономно на вашем локальном устройстве. Настоящая политика описывает, какие данные могут собираться или передаваться при использовании приложения.

## Сбор данных

### Локальные функции (данные не передаются)

Следующие функции обрабатывают все данные локально и не отправляют информацию по сети:

- **Color Picker (Пипетка цвета)** — захватывает пиксели экрана локально
- **Window Inspector (Spy++) (Инспектор окон)** — считывает свойства окон через локальные API Windows
- **Always-on-Top (Поверх всех окон)** — изменяет порядок слоёв окон локально
- **Brightness Sync (Синхронизация яркости)** — считывает данные аппаратных датчиков локально
- **Bulk File Copy / Delete (Массовое копирование / удаление файлов)** — работает только с локальной файловой системой
- **Defender Toggle (Переключатель Defender)** — изменяет локальные настройки Windows Defender

### Функции, использующие сетевой доступ

- **Snap Translate (Перевод скриншотов, OCR и перевод изображений):** При использовании онлайн-OCR или перевода изображений ваш снимок экрана отправляется стороннему поставщику API (Baidu Cloud, Tencent Cloud или Youdao) для обработки. Данные изображений передаются безопасно по протоколу HTTPS. Мы не храним и не сохраняем ваши снимки экрана на каких-либо контролируемых нами серверах.
- **Автономный OCR:** При использовании автономного режима PaddleOCR всё распознавание текста выполняется локально. Данные не передаются.
- **Проверка обновлений:** Приложение периодически проверяет наличие новых версий на GitHub. Передаётся только текущая версия приложения; личные данные не включаются.
- **Проверка лицензии:** При активации лицензии приложение связывается с нашим сервером для проверки лицензионного ключа. Передаются только лицензионный ключ, идентификатор устройства и версия приложения.

## Сторонние поставщики API

При использовании функций онлайн-OCR или перевода ваши данные обрабатываются в соответствии с политикой конфиденциальности соответствующего поставщика:

- **Baidu Cloud API:** https://ai.baidu.com/ai-doc/REFERENCE/kk3dwjg7d
- **Tencent Cloud API:** https://cloud.tencent.com/document/product/301/11470
- **Youdao API:** https://fanyi.youdao.com/openapi

Вы самостоятельно настраиваете собственные API-ключи для этих сервисов.

## Хранение данных

- **Конфигурация:** Настройки приложения хранятся локально в JSON-файле в каталоге приложения (или в профиле пользователя для версий из Store).
- **Лицензионная информация:** Статус лицензии хранится в реестре Windows в вашем профиле пользователя.
- **Журналы сбоев:** В случае сбоя приложения файл журнала сохраняется локально. Журналы сбоев никогда не загружаются автоматически.

## Данные, которые мы НЕ собираем

- Мы не собираем личную информацию (имя, электронную почту, адрес) через приложение
- Мы не используем аналитику, телеметрию или отслеживание
- Мы не используем файлы cookie
- Мы не передаём и не продаём данные пользователей

## Ваши права

Вы имеете право:
- Использовать приложение без предоставления личных данных (автономные функции)
- Удалять все локальные файлы конфигурации и журналы в любое время
- Отказаться от использования функций, требующих сетевого подключения

## Конфиденциальность детей

Данное приложение не собирает сознательно данные детей младше 13 лет.

# الخصوصية وحماية البيانات

**آخر تحديث:** مارس 2026
**المطوّر:** Wengeng Zhang (xmulitech@gmail.com)

## نظرة عامة

صُمّم QuickUtilitiesSuite مع مراعاة الخصوصية. تعمل معظم الميزات بالكامل دون اتصال بالإنترنت على جهازك المحلي. توضّح هذه السياسة البيانات التي قد يتم جمعها أو نقلها عند استخدامك للتطبيق.

## جمع البيانات

### الميزات المحلية فقط (لا يتم نقل أي بيانات)

تعالج الميزات التالية جميع البيانات محليًا ولا ترسل أي معلومات عبر الشبكة:

- **Color Picker (منتقي الألوان)** — يلتقط وحدات البكسل من الشاشة محليًا
- **Window Inspector (Spy++) (مفتش النوافذ)** — يقرأ خصائص النوافذ عبر واجهات Windows API المحلية
- **Always-on-Top (دائمًا في المقدمة)** — يعدّل ترتيب طبقات النوافذ محليًا
- **Brightness Sync (مزامنة السطوع)** — يقرأ بيانات مستشعرات الأجهزة محليًا
- **Bulk File Copy / Delete (نسخ / حذف الملفات بالجملة)** — يعمل على نظام الملفات المحلي فقط
- **Defender Toggle (مفتاح Defender)** — يعدّل إعدادات Windows Defender المحلية

### الميزات التي تستخدم الوصول إلى الشبكة

- **Snap Translate (ترجمة لقطة الشاشة، OCR وترجمة الصور):** عند استخدام OCR عبر الإنترنت أو ترجمة الصور، يتم إرسال لقطة الشاشة إلى مزوّد API تابع لجهة خارجية (Baidu Cloud أو Tencent Cloud أو Youdao) للمعالجة. تُنقل بيانات الصور بشكل آمن عبر HTTPS. لا نقوم بتخزين أو الاحتفاظ بلقطات الشاشة الخاصة بك على أي خادم نتحكم فيه.
- **OCR دون اتصال:** عند استخدام وضع PaddleOCR دون اتصال، يتم التعرف على النص بالكامل محليًا. لا يتم نقل أي بيانات.
- **التحقق من التحديثات:** يتحقق التطبيق دوريًا من الإصدارات الجديدة على GitHub. يتم إرسال إصدار التطبيق الحالي فقط؛ ولا تُضمَّن أي بيانات شخصية.
- **التحقق من الترخيص:** يتصل تنشيط الترخيص بخادمنا للتحقق من صحة مفتاح الترخيص. يتم نقل مفتاح الترخيص ومعرّف الجهاز وإصدار التطبيق فقط.

## مزوّدو API من جهات خارجية

عند استخدام ميزات OCR أو الترجمة عبر الإنترنت، تتم معالجة بياناتك وفقًا لسياسة الخصوصية الخاصة بالمزوّد المعني:

- **Baidu Cloud API:** https://ai.baidu.com/ai-doc/REFERENCE/kk3dwjg7d
- **Tencent Cloud API:** https://cloud.tencent.com/document/product/301/11470
- **Youdao API:** https://fanyi.youdao.com/openapi

أنت مسؤول عن تهيئة مفاتيح API الخاصة بك لهذه الخدمات.

## تخزين البيانات

- **الإعدادات:** تُخزَّن إعدادات التطبيق محليًا في ملف JSON داخل مجلد التطبيق (أو ضمن ملف تعريف المستخدم لإصدارات Store).
- **معلومات الترخيص:** يُخزَّن حالة الترخيص في سجل Windows ضمن ملف تعريف المستخدم الخاص بك.
- **سجلات الأعطال:** في حالة تعطّل التطبيق، يُحفظ ملف السجل محليًا. لا يتم رفع سجلات الأعطال تلقائيًا أبدًا.

## البيانات التي لا نجمعها

- لا نجمع معلومات شخصية (الاسم، البريد الإلكتروني، العنوان) عبر التطبيق
- لا نستخدم أدوات التحليل أو القياس عن بُعد أو التتبع
- لا نستخدم ملفات تعريف الارتباط (cookies)
- لا نشارك أو نبيع أي بيانات للمستخدمين

## حقوقك

لديك الحق في:
- استخدام التطبيق دون تقديم أي بيانات شخصية (الميزات المحلية)
- حذف جميع ملفات الإعدادات والسجلات المحلية في أي وقت
- اختيار عدم استخدام الميزات التي تعتمد على الشبكة

## خصوصية الأطفال

لا يجمع هذا التطبيق عن عمد بيانات من الأطفال دون سن 13 عامًا.

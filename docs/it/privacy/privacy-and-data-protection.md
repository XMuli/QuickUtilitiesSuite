# Privacy e Protezione dei Dati

- Per la traduzione di immagini o OCR, gli screenshot vengono inviati ad API di terze parti; l'utilizzo di queste funzionalità implica l'accettazione dei loro termini. Queste funzionalità richiedono accesso a internet.
- Le altre funzionalità funzionano localmente, non richiedono permessi di rete e mantengono i dati sul dispositivo.

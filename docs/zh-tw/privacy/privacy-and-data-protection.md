# 隱私與資料保護

**最後更新：** 2026 年 3 月
**開發者：** Wengeng Zhang (xmulitech@gmail.com)

## 概述

QuickUtilitiesSuite 在設計時充分考量了隱私保護。大多數功能完全在您的本機裝置上離線運行。本政策說明您在使用本應用程式時，可能會收集或傳輸哪些資料。

## 資料收集

### 僅限本機的功能（不傳輸任何資料）

以下功能在本機處理所有資料，不會透過網路傳送任何資訊：

- **Color Picker（取色器）** — 在本機擷取螢幕像素
- **Window Inspector (Spy++)（視窗檢查器）** — 透過本機 Windows API 讀取視窗屬性
- **Always-on-Top（視窗置頂）** — 在本機修改視窗層級
- **Brightness Sync（亮度同步）** — 在本機讀取硬體感測器資料
- **Bulk File Copy / Delete（批次檔案複製 / 刪除）** — 僅操作本機檔案系統
- **Defender Toggle（Defender 開關）** — 修改本機 Windows Defender 設定

### 需要網路存取的功能

- **Snap Translate（截圖翻譯，OCR 與圖片翻譯）：** 當您使用線上 OCR 或圖片翻譯時，您的截圖將會傳送至第三方 API 供應商（百度雲、騰訊雲或有道）進行處理。圖片資料透過 HTTPS 安全傳輸。我們不會在任何我們控制的伺服器上儲存或保留您的截圖。
- **離線 OCR：** 使用 PaddleOCR 離線模式時，所有文字辨識均在本機完成，不會傳輸任何資料。
- **更新檢查：** 應用程式會定期連線 GitHub 檢查新版本。僅傳送您目前的應用程式版本號，不包含任何個人資料。
- **授權驗證：** 授權啟用時會連線我們的伺服器以驗證授權金鑰。僅傳輸授權金鑰、裝置識別碼及應用程式版本。

## 第三方 API 供應商

使用線上 OCR 或翻譯功能時，您的資料將依據相應供應商的隱私政策進行處理：

- **百度雲 API：** https://ai.baidu.com/ai-doc/REFERENCE/kk3dwjg7d
- **騰訊雲 API：** https://cloud.tencent.com/document/product/301/11470
- **有道 API：** https://fanyi.youdao.com/openapi

您需自行設定這些服務的 API 金鑰。

## 資料儲存

- **設定檔：** 應用程式設定以 JSON 檔案形式儲存在應用程式目錄中（商店版則儲存在使用者設定檔目錄）。
- **授權資訊：** 授權狀態儲存在您使用者設定檔下的 Windows 登錄檔中。
- **當機記錄：** 若應用程式當機，記錄檔案會儲存在本機。當機記錄絕不會自動上傳。

## 我們不收集的資料

- 我們不會透過應用程式收集個人資訊（姓名、電子郵件、地址）
- 我們不使用分析工具、遙測或追蹤技術
- 我們不使用 Cookie
- 我們不會分享或出售任何使用者資料

## 您的權利

您有權：
- 在不提供任何個人資料的情況下使用本應用程式（離線功能）
- 隨時刪除所有本機設定檔與記錄檔案
- 選擇不使用需要網路的功能

## 兒童隱私

本應用程式不會故意收集 13 歲以下兒童的資料。

## 政策變更

我們可能會不定期更新本政策。變更將在應用程式的版本更新說明中註明。

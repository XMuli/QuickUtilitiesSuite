# 使用案例

Quick Utilities 產品是為了那些容易被桌面小摩擦拖慢的 Windows 工作流而打造的。

## 多螢幕桌面

`Quick BrightnessSync` 適合長時間依賴外接顯示器的桌面。對於開發、分析、交易、運營與內容審核等長時間工作場景尤其實用，因為這些場景中的視覺舒適度會隨時間改變。

## 專注多工

`Quick AlwaysOnTop` 適合在一個視窗必須持續可見、而其他工作區又不斷變化的情況下使用。它很適合辦公效率、即時支援、會議、研究與技術工作流。

## 技術與排障工作

`Quick WindowInspector`、`Quick AlwaysOnTop`、`Quick BulkFileCopy` 與 `Quick BulkFileDelete` 適合那些日常工作中需要處理日誌、工具、套件資料夾與重複桌面任務的環境。

## 更完整的桌面工具需求

當同一台工作站同時需要顯示控制、多工支援、重檔案工具、翻譯、OCR 與擷取工具時，`Quick Utilities Suite` 會是更合適的選擇。

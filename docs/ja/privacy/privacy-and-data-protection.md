# プライバシーとデータ保護

**最終更新日：** 2026年3月
**開発者：** Wengeng Zhang (xmulitech@gmail.com)

## 概要

QuickUtilitiesSuite はプライバシーを重視して設計されています。ほとんどの機能はお使いのデバイス上で完全にオフラインで動作します。本ポリシーでは、アプリケーションご利用時に収集または送信される可能性のあるデータについてご説明します。

## データ収集

### ローカル専用機能（データ送信なし）

以下の機能はすべてのデータをローカルで処理し、ネットワーク経由で情報を送信することはありません：

- **Color Picker（カラーピッカー）** — 画面のピクセルをローカルでキャプチャ
- **Window Inspector (Spy++)（ウィンドウインスペクター）** — ローカルの Windows API を通じてウィンドウプロパティを読み取り
- **Always-on-Top（常に最前面）** — ウィンドウのレイヤー順序をローカルで変更
- **Brightness Sync（輝度同期）** — ハードウェアセンサーのデータをローカルで読み取り
- **Bulk File Copy / Delete（一括ファイルコピー / 削除）** — ローカルファイルシステム上でのみ動作
- **Defender Toggle（Defender 切り替え）** — ローカルの Windows Defender 設定を変更

### ネットワークアクセスを使用する機能

- **Snap Translate（スクリーンショット翻訳、OCR と画像翻訳）：** オンライン OCR または画像翻訳を使用すると、スクリーンショットがサードパーティ API プロバイダー（百度クラウド、テンセントクラウド、または有道）に送信され処理されます。画像データは HTTPS で安全に送信されます。当方が管理するサーバーにスクリーンショットを保存・保持することはありません。
- **オフライン OCR：** PaddleOCR オフラインモードを使用する場合、すべてのテキスト認識はローカルで実行されます。データは一切送信されません。
- **アップデートチェック：** アプリケーションは定期的に GitHub で新バージョンを確認します。送信されるのは現在のアプリバージョンのみで、個人データは含まれません。
- **ライセンス認証：** ライセンスのアクティベーション時に、ライセンスキーの検証のためサーバーに接続します。送信されるのはライセンスキー、デバイス識別子、アプリバージョンのみです。

## サードパーティ API プロバイダー

オンライン OCR または翻訳機能を使用する場合、お客様のデータは各プロバイダーのプライバシーポリシーに従って処理されます：

- **百度クラウド API：** https://ai.baidu.com/ai-doc/REFERENCE/kk3dwjg7d
- **テンセントクラウド API：** https://cloud.tencent.com/document/product/301/11470
- **有道 API：** https://fanyi.youdao.com/openapi

これらのサービスの API キーはお客様ご自身で設定していただく必要があります。

## データの保存

- **設定：** アプリの設定はアプリケーションディレクトリ内の JSON ファイルに保存されます（ストア版ではユーザープロファイル内）。
- **ライセンス情報：** ライセンスの状態はユーザープロファイル配下の Windows レジストリに保存されます。
- **クラッシュログ：** アプリケーションがクラッシュした場合、ログファイルがローカルに保存されます。クラッシュログが自動的にアップロードされることはありません。

## 当方が収集しないデータ

- アプリケーションを通じて個人情報（氏名、メールアドレス、住所）を収集することはありません
- アナリティクス、テレメトリー、トラッキングは使用していません
- Cookie は使用していません
- ユーザーデータの共有や販売は行いません

## お客様の権利

お客様には以下の権利があります：
- 個人データを提供することなくアプリケーションを使用する権利（オフライン機能）
- ローカルの設定ファイルやログファイルをいつでも削除する権利
- ネットワーク依存の機能を使用しない選択をする権利

## 児童のプライバシー

本アプリケーションは、13歳未満のお子様のデータを故意に収集することはありません。

## 本ポリシーの変更

本ポリシーは随時更新される場合があります。変更はアプリケーションのリリースノートに記載されます。

# 适用场景

Quick Utilities 产品面向的是那些桌面小摩擦会不断累积的 Windows 工作流。

## 多屏桌面

`Quick BrightnessSync` 适合长期依赖外接显示器的桌面环境，尤其适用于开发、分析、交易、运维和值守等长时间多屏工作场景。

## 专注多任务处理

`Quick AlwaysOnTop` 适合那些必须让某个窗口持续保持可见，同时又要继续处理其他任务的工作流，包括办公协作、实时支持、会议、研究和技术工作。

## 技术与排障工作

`Quick WindowInspector`、`Quick AlwaysOnTop`、`Quick BulkFileCopy` 和 `Quick BulkFileDelete` 适合日志、工具窗口、项目目录与重复桌面任务较多的环境。

## 更完整的桌面工具集需求

当一台工作站同时需要显示控制、多任务支持、文件密集型工具、翻译、OCR 与截图能力时，`Quick Utilities Suite` 会更合适。

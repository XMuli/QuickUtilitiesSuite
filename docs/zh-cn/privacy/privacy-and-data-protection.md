# 隐私与数据保护

**最后更新：** 2026 年 3 月
**开发者：** Wengeng Zhang (xmulitech@gmail.com)

## 概述

QuickUtilitiesSuite 在设计时充分考虑了用户隐私。大多数功能完全在本地设备上离线运行。本政策说明了您在使用本应用时可能涉及的数据收集或传输情况。

## 数据收集

### 仅限本地的功能（不传输任何数据）

以下功能在本地处理所有数据，不会通过网络发送任何信息：

- **取色器** — 在本地捕获屏幕像素
- **窗口检查器 (Spy++)** — 通过本地 Windows API 读取窗口属性
- **窗口置顶** — 在本地修改窗口层级
- **亮度同步** — 在本地读取硬件传感器数据
- **批量文件复制 / 删除** — 仅操作本地文件系统
- **Defender 开关** — 修改本地 Windows Defender 设置

### 需要使用网络的功能

- **截图翻译（OCR 与图片翻译）：** 当您使用在线 OCR 或图片翻译时，截图会被发送至第三方 API 提供商（百度云、腾讯云或有道）进行处理。图片数据通过 HTTPS 安全传输。我们不会在任何我们控制的服务器上存储或保留您的截图。
- **离线 OCR：** 使用 PaddleOCR 离线模式时，所有文字识别均在本地完成，不会传输任何数据。
- **更新检查：** 应用会定期检查 GitHub 上的新版本。仅发送当前应用版本号，不包含任何个人数据。
- **许可证验证：** 许可证激活时会连接我们的服务器以验证许可证密钥。仅传输许可证密钥、设备标识符和应用版本号。

## 第三方 API 提供商

使用在线 OCR 或翻译功能时，您的数据将根据相应提供商的隐私政策进行处理：

- **百度云 API：** https://ai.baidu.com/ai-doc/REFERENCE/kk3dwjg7d
- **腾讯云 API：** https://cloud.tencent.com/document/product/301/11470
- **有道 API：** https://fanyi.youdao.com/openapi

您需要自行配置这些服务的 API 密钥。

## 数据存储

- **配置信息：** 应用设置以 JSON 文件形式存储在应用目录内（商店版存储在用户配置文件夹中）。
- **许可证信息：** 许可证状态存储在您用户配置下的 Windows 注册表中。
- **崩溃日志：** 应用崩溃时会在本地保存日志文件。崩溃日志不会被自动上传。

## 我们不收集的数据

- 我们不会通过应用收集个人信息（姓名、电子邮件、地址）
- 我们不使用分析工具、遥测或追踪技术
- 我们不使用 Cookie
- 我们不会分享或出售任何用户数据

## 您的权利

您有权：
- 在不提供任何个人数据的情况下使用本应用（离线功能）
- 随时删除所有本地配置和日志文件
- 选择不使用需要网络的功能

## 儿童隐私

本应用不会故意收集 13 岁以下儿童的数据。

## 政策变更

我们可能会不时更新本政策。变更内容将在应用的发行说明中注明。

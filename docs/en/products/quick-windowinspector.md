### Key Features

**Complete Window Information**
Displays window handle, process ID (PID), window title, client area dimensions (rectangle), device pixel ratio (DPR), application path, and other detailed information — ideal for window inspection, debugging, and management.

**Visual Border Highlight**
Automatically displays a highlighted border around the target window, clearly identifying which window is currently being inspected. Border appearance is fully customizable.

**Convenient Operation**
Global hotkey for instant activation, hover over any window to view its information, and an option to detect only top-level windows.

---

### Why Choose Quick WindowInspector

**Simpler Than Spy++**
No need to navigate complex tree structures — hover your mouse to instantly retrieve window information.

**More Comprehensive Information**
Beyond basic handle and PID, also provides DPI, client area dimensions, and other commonly needed development data.

**More Intuitive Visualization**
Highlighted borders make it immediately clear which window you're inspecting, eliminating confusion.

### Use Cases

**Software Developers**

Obtain window identifiers and position data when writing UI automation scripts.

**System Administrators**
View application window information to locate problematic programs or processes.

---

### Getting Started

1. **Activate the Tool**
   Use a global hotkey or click the system tray icon to activate

2. **Hover Over a Window**
   Move your mouse over the window you want to inspect

3. **View Information**
   Window details are displayed automatically, with a highlighted border identifying the target window

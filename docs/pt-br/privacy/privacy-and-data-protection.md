# Privacidade e Protecao de Dados

- Para traducao de imagens ou OCR, capturas de tela sao enviadas a APIs de terceiros para obter resultados; usar esses recursos implica concordancia com seus termos. Esses recursos requerem acesso a internet.
- Outros recursos funcionam localmente, nao precisam de permissoes de rede e mantem os dados no seu dispositivo.

Politicas de privacidade dos provedores de API:

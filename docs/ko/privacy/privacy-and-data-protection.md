# 개인정보 보호 및 데이터 보호

**최종 업데이트:** 2026년 3월
**개발자:** Wengeng Zhang (xmulitech@gmail.com)

## 개요

QuickUtilitiesSuite는 개인정보 보호를 염두에 두고 설계되었습니다. 대부분의 기능은 사용자의 로컬 기기에서 완전히 오프라인으로 작동합니다. 본 정책은 애플리케이션 사용 시 수집 또는 전송될 수 있는 데이터에 대해 설명합니다.

## 데이터 수집

### 로컬 전용 기능 (데이터 전송 없음)

다음 기능은 모든 데이터를 로컬에서 처리하며, 네트워크를 통해 어떠한 정보도 전송하지 않습니다:

- **Color Picker (색상 선택기)** — 화면 픽셀을 로컬에서 캡처
- **Window Inspector (Spy++) (윈도우 검사기)** — 로컬 Windows API를 통해 윈도우 속성을 읽기
- **Always-on-Top (항상 위에)** — 로컬에서 윈도우 레이어 순서를 변경
- **Brightness Sync (밝기 동기화)** — 하드웨어 센서 데이터를 로컬에서 읽기
- **Bulk File Copy / Delete (일괄 파일 복사 / 삭제)** — 로컬 파일 시스템에서만 작동
- **Defender Toggle (Defender 전환)** — 로컬 Windows Defender 설정을 변경

### 네트워크 접근이 필요한 기능

- **Snap Translate (스크린샷 번역, OCR 및 이미지 번역):** 온라인 OCR 또는 이미지 번역을 사용할 때 스크린샷이 타사 API 제공업체(Baidu Cloud, Tencent Cloud 또는 Youdao)로 전송되어 처리됩니다. 이미지 데이터는 HTTPS를 통해 안전하게 전송됩니다. 당사가 관리하는 서버에 스크린샷을 저장하거나 보관하지 않습니다.
- **오프라인 OCR:** PaddleOCR 오프라인 모드를 사용할 때 모든 텍스트 인식은 로컬에서 수행됩니다. 데이터가 전송되지 않습니다.
- **업데이트 확인:** 애플리케이션은 주기적으로 GitHub에서 새 버전을 확인합니다. 현재 앱 버전만 전송되며, 개인 데이터는 포함되지 않습니다.
- **라이선스 확인:** 라이선스 활성화 시 라이선스 키를 검증하기 위해 서버에 연결합니다. 라이선스 키, 기기 식별자 및 앱 버전만 전송됩니다.

## 타사 API 제공업체

온라인 OCR 또는 번역 기능을 사용할 때 사용자의 데이터는 해당 제공업체의 개인정보 보호 정책에 따라 처리됩니다:

- **Baidu Cloud API:** https://ai.baidu.com/ai-doc/REFERENCE/kk3dwjg7d
- **Tencent Cloud API:** https://cloud.tencent.com/document/product/301/11470
- **Youdao API:** https://fanyi.youdao.com/openapi

이러한 서비스에 대한 API 키는 사용자가 직접 설정해야 합니다.

## 데이터 저장

- **설정:** 앱 설정은 애플리케이션 디렉토리 내의 JSON 파일에 저장됩니다 (스토어 버전의 경우 사용자 프로필 내).
- **라이선스 정보:** 라이선스 상태는 사용자 프로필 하위의 Windows 레지스트리에 저장됩니다.
- **충돌 로그:** 애플리케이션이 충돌하면 로그 파일이 로컬에 저장됩니다. 충돌 로그는 자동으로 업로드되지 않습니다.

## 수집하지 않는 데이터

- 애플리케이션을 통해 개인 정보(이름, 이메일, 주소)를 수집하지 않습니다
- 분석, 원격 측정 또는 추적을 사용하지 않습니다
- 쿠키를 사용하지 않습니다
- 사용자 데이터를 공유하거나 판매하지 않습니다

## 사용자의 권리

사용자는 다음 권리를 가집니다:
- 개인 데이터를 제공하지 않고 애플리케이션을 사용할 권리 (오프라인 기능)
- 언제든지 모든 로컬 설정 및 로그 파일을 삭제할 권리
- 네트워크 의존 기능을 사용하지 않을 권리

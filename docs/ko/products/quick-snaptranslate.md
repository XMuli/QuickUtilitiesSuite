### 언어 장벽을 허물다

이미지, 문서, 웹페이지에서 외국어 텍스트를 만나셨나요? Quick SnapTranslate를 사용하면 스크린샷을 캡처하고, 텍스트를 자동으로 인식하고, 원하는 언어로 번역하는 과정을 단 한 번의 동작으로 완료할 수 있습니다. 이미지에 포함된 텍스트도 쉽게 이해할 수 있습니다. 온라인과 오프라인 OCR을 모두 지원하여 속도와 프라이버시 사이에서 최적의 균형을 제공하며, 전문가 수준의 인식 정확도를 실현합니다.

### 주요 기능

**스마트 스크린샷 인식**
원클릭으로 스크린샷을 캡처하고 이미지 내 텍스트를 자동으로 인식합니다. 지능형 윈도우 감지로 필요한 영역을 정확하게 캡처할 수 있습니다.

**즉시 번역**
인식된 텍스트가 자동으로 대상 언어로 번역됩니다. 다양한 언어 쌍을 지원하여 다국어 독해를 간편하고 효율적으로 만들어줍니다.

**유연한 인식 옵션**
필요에 따라 속도를 위한 온라인 OCR(Tencent Cloud API) 또는 프라이버시를 위한 오프라인 OCR(PaddleOCR)을 선택할 수 있습니다.

**실용적인 보조 기능**
스크린샷 도구 모음에서 저장, 복사, 화면 고정 기능을 지원합니다. 고정 기능으로 중요한 콘텐츠를 데스크톱에 표시하여 쉽게 참고할 수 있습니다.

---

### Quick SnapTranslate를 선택해야 하는 이유

**수동 입력보다 10배 빠른 속도**
외국어 텍스트를 번역 도구에 수동으로 입력할 필요가 없습니다 — 스크린샷을 찍으면 즉시 인식하고 번역합니다.

**오프라인 인식 지원**
내장된 PaddleOCR 엔진으로 인터넷 연결 없이도 텍스트 인식이 가능하며 민감한 데이터를 보호합니다.

**다양한 시나리오에서 작동**
이미지, 웹페이지, PDF, 동영상 자막 — 텍스트가 포함된 모든 콘텐츠를 인식하고 번역할 수 있습니다.

### 사용 사례

**다국어 전문가**
외국어 문서, 이메일, 웹 콘텐츠를 빠르게 이해하여 업무 효율성을 높입니다.

**학생 및 학습자**
외국어 교재나 연구 논문의 낯선 구절을 번역하여 학습을 지원합니다.

**개발자**
외국어 기술 문서, 오류 메시지, UI 텍스트를 확인하여 문제를 빠르게 파악하고 해결합니다.

### 시작하기

1. **스크린샷 활성화**
   글로벌 단축키를 사용하거나 시스템 트레이 아이콘을 클릭하여 스크린샷 기능을 활성화합니다

2. **영역 선택**
   인식할 텍스트 주변에 상자를 그립니다 — 지능형 윈도우 감지를 지원합니다

3. **결과 확인**
   텍스트가 자동으로 인식되고 번역됩니다 — 결과를 복사, 저장 또는 화면에 고정할 수 있습니다

**화면의 모든 위치에서 정밀하게 색상을 캡처합니다.**

---

### 간편하고 정확한 색상 선택

인터페이스 디자인, 색상 배합 조정, UI 요소 디버깅 등 어떤 작업을 하든 Quick ColorPicker는 화면의 모든 위치에서 색상 값을 확대하여 정밀하게 캡처할 수 있도록 도와줍니다. 실시간 돋보기가 커서를 따라가며 모든 픽셀을 상세히 보여줍니다. 다양한 출력 형식으로 디자인, 개발, 창작 작업의 다양한 워크플로우를 지원합니다.

### 주요 기능

**픽셀 단위 정밀 색상 캡처**
실시간 돋보기가 커서 아래의 픽셀을 표시하여 정확히 필요한 색상을 정밀하게 지정할 수 있습니다. 멀티 모니터 환경을 완벽하게 지원하며 디스플레이 간 부드러운 커서 추적이 가능합니다.

**다양한 색상 형식**
RGB, HEX, RGB+HEX, HEX+RGB 등 다양한 형식으로 색상을 출력하여 디자인, 개발, 색상 매칭 시나리오에 대응합니다.

**스마트 보조 도구**
정밀한 위치 지정을 위한 십자선 오버레이, 미세 조정을 위한 키보드 방향키, 즉시 활성화를 위한 글로벌 단축키. 모든 세부 사항이 효율성을 위해 설계되었습니다.

---

### Quick ColorPicker를 선택해야 하는 이유

**스크린샷보다 빠른 속도**
스크린샷을 찍고 이미지 편집기에서 열어 별도의 색상 추출기를 사용할 필요가 없습니다. 하나의 단축키로 즉시 색상 값을 얻을 수 있습니다.

**시스템 도구보다 전문적**
사용자 정의 돋보기 외형, 대문자/소문자 HEX 출력 지원 등 추가 전문 옵션을 제공합니다.

**완벽한 멀티 모니터 지원**
멀티 디스플레이 환경에서 돋보기가 모든 화면에 걸쳐 커서를 정확하게 추적하며, 어긋남이나 오프셋 문제가 없습니다.

---

### 사용 사례

**UI 디자이너**
디자인 시안이나 참고 웹사이트에서 빠르게 색상 팔레트를 추출하여 일관된 비주얼 스타일을 유지합니다.

**프론트엔드 개발자**
UI 디버깅 시 정확한 요소 색상을 캡처하여 구현이 디자인 사양과 정확히 일치하는지 확인합니다.

**색상 애호가**
좋아하는 이미지, 웹사이트, 앱에서 색상 영감을 추출하여 나만의 색상 라이브러리를 구축합니다.

---

### 시작하기

1. **도구 실행**
   Quick ColorPicker를 실행하거나 글로벌 단축키로 활성화합니다

2. **커서 이동**
   샘플링하려는 영역 위로 마우스를 올리면 돋보기가 실시간으로 픽셀을 표시합니다

3. **색상 캡처**
   클릭하거나 스페이스바를 눌러 색상 값을 클립보드에 직접 복사합니다

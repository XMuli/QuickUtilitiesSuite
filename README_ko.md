## <img src="./docs/public/images/quick-logo/Quick ColorPicker.svg" width="64" align="left" style="margin-right: 16px;" /> Quick ColorPicker

**화면 어디서든 정확한 색상을 캡처하세요.**

인터페이스 디자인, 색상 배합 조정, UI 요소 디버깅 등 어떤 작업을 하든 Quick ColorPicker는 화면의 모든 위치에서 색상 값을 확대하고 정밀하게 캡처할 수 있도록 도와줍니다. 실시간 돋보기가 커서를 따라다니며 모든 픽셀을 세밀하게 보여줍니다. 다양한 출력 형식(RGB / HEX / RGB+HEX)과 원활한 멀티 모니터 지원으로 빠르고 정확한 색상 추출이 가능합니다.

<a href="https://apps.microsoft.com/detail/9N2XV7TJTN2J"><img src="https://get.microsoft.com/images/ko-kr%20dark.svg" width="200" /></a>

## <img src="./docs/public/images/quick-logo/Quick BulkFilecopy.svg" width="64" align="left" style="margin-right: 16px;" /> Quick BulkFileCopy

**초고속 대량 파일 복사 — 기다림은 그만, 바로 작업을 시작하세요.**

Windows 탐색기에서 node_modules 폴더를 복사하는 데 몇 분이나 걸리는 것에 지치셨나요? Quick BulkFileCopy는 대량의 소형 파일이 포함된 디렉토리를 처리하기 위해 특별히 설계되어, 기본 시스템 도구보다 몇 배 빠르게 복사합니다. 드래그 앤 드롭 조작, 실시간 진행 상황 추적, 자동 무결성 검증으로 파일 복사를 간편하고 안정적으로 만들어 줍니다.

<a href="https://apps.microsoft.com/detail/9P0MCT80QQTL"><img src="https://get.microsoft.com/images/ko-kr%20dark.svg" width="200" /></a>

## <img src="./docs/public/images/quick-logo/Quick BulkFileDelete.svg" width="64" align="left" style="margin-right: 16px;" /> Quick BulkFileDelete

**대용량 디렉토리의 초고속 삭제 — 끝없는 기다림은 이제 그만.**

비대한 node_modules 폴더를 삭제하려 할 때 Windows 탐색기가 '남은 시간 계산 중'으로 멈추나요? Quick BulkFileDelete는 고성능 삭제 알고리즘을 사용하여 삭제 시간을 대폭 단축하고 시스템 멈춤 현상을 해소합니다. 삭제 전 확인 기능으로 실수로 인한 삭제를 방지하며, 상세 로그가 모든 과정을 기록하여 완벽한 추적이 가능합니다.

## <img src="./docs/public/images/quick-logo/Quick snapOCR.svg" width="64" align="left" style="margin-right: 16px;" /> Quick SnapOCR

**원클릭 스크린샷 + OCR — 이미지, 웹페이지, 문서에서 텍스트를 추출하세요.**

이미지 속에 복사해야 할 텍스트를 발견하셨나요? 직접 입력할 필요 없습니다. 스크린샷을 찍으면 Quick SnapOCR이 캡처된 영역 내의 텍스트를 자동으로 인식하여 클립보드에 바로 복사합니다. PDF 스크린샷, 웹페이지 그래픽, 동영상 자막 등 어떤 것이든 텍스트 추출이 손쉽습니다.

## <img src="./docs/public/images/quick-logo/Quick SnapTranslate.svg" width="64" align="left" style="margin-right: 16px;" /> Quick SnapTranslate

**캡처, 인식, 번역을 원클릭으로 — 다국어 작업을 손쉽게.**

이미지, 문서 또는 웹페이지에서 외국어 텍스트를 만나셨나요? Quick SnapTranslate는 스크린샷을 캡처하고 텍스트를 자동으로 인식한 후 원하는 언어로 번역합니다 — 단 한 번의 동작으로 모든 것이 완료됩니다. 온라인 OCR(텐센트 클라우드 API)과 오프라인 OCR(PaddleOCR)을 모두 지원하여 속도와 프라이버시의 균형을 맞추며, 화면 고정 기능으로 편리하게 참조할 수 있습니다.

## <img src="./docs/public/images/quick-logo/Quick Windowinspector.svg" width="64" align="left" style="margin-right: 16px;" /> Quick WindowInspector

**모든 창의 상세 정보를 조회 — Spy++보다 간편하고 직관적입니다.**

아무 창 위에 마우스를 올리면 핸들, PID, 제목, 클라이언트 영역 크기, 장치 픽셀 비율(DPR), 애플리케이션 경로 등의 정보를 즉시 확인할 수 있습니다. 대상 창은 커스터마이징 가능한 테두리로 자동 강조 표시되며, 전역 단축키로 즉시 활성화할 수 있습니다. 소프트웨어 개발, UI 자동화 테스트, 시스템 관리에 필수적인 도구입니다.

<a href="https://apps.microsoft.com/detail/9N8MVQV88Z2T"><img src="https://get.microsoft.com/images/ko-kr%20dark.svg" width="200" /></a>

## <img src="./docs/public/images/quick-logo/Quick AlwaysOnTop.svg" width="64" align="left" style="margin-right: 16px;" /> Quick AlwaysOnTop

**단축키 하나로 원하는 창을 최상위에 고정 — 멀티태스킹이 더없이 편리해집니다.**

코드를 작성하면서 문서를 참조해야 하나요? 계산기나 번역기를 항상 보이게 하고 싶으신가요? 전역 단축키(기본값 Ctrl+Shift+T) 하나로 원하는 창을 즉시 고정하거나 해제할 수 있어 중요한 정보를 항상 최상위에 유지합니다. 고정된 창에는 커스터마이징 가능한 강조 테두리와 선택적 사운드 효과가 표시되어 현재 상태를 한눈에 파악할 수 있습니다.

<a href="https://apps.microsoft.com/detail/9NR3H8Q42N4S"><img src="https://get.microsoft.com/images/ko-kr%20dark.svg" width="200" /></a>

## <img src="./docs/public/images/quick-logo/Quick DefenderToggle.svg" width="64" align="left" style="margin-right: 16px;" /> Quick DefenderToggle

**Windows Defender를 빠르게 활성화 또는 비활성화 — 고급 사용자를 위한 완벽한 제어.**

그룹 정책 편집기나 레지스트리를 탐색할 필요 없이, 세 가지 제어 모드(중지 / 시작 / 강제 활성화)로 Microsoft Defender 바이러스 백신을 원클릭으로 관리할 수 있습니다. 실시간 상태 피드백과 상세 작업 로그로 매 단계를 명확히 파악할 수 있습니다. 표준 그룹 정책 메커니즘을 사용하여 안전하고 안정적인 제어를 보장합니다.

> 관리자 권한이 필요합니다. Defender를 비활성화하면 시스템 보안이 저하됩니다 — 필요한 경우에만 사용하고 신속히 보호를 다시 활성화하세요.

<a href="https://apps.microsoft.com/detail/9PFQQ9CPP9P3"><img src="https://get.microsoft.com/images/ko-kr%20dark.svg" width="200" /></a>

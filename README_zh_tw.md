## <img src="./docs/public/images/quick-logo/Quick ColorPicker.svg" width="64" align="left" style="margin-right: 16px;" /> Quick ColorPicker

**精準擷取螢幕上任意位置的色彩。**

無論你是設計介面、微調配色方案，還是除錯 UI 元素，Quick ColorPicker 都能幫助你放大並精確擷取螢幕上任意位置的色彩值。即時放大鏡跟隨游標移動，清晰呈現每一個像素。支援多種輸出格式（RGB / HEX / RGB+HEX）與多螢幕環境，讓取色快速又精準。

## <img src="./docs/public/images/quick-logo/Quick snapOCR.svg" width="64" align="left" style="margin-right: 16px;" /> Quick SnapOCR

**一鍵截圖 + OCR——從任何圖片、網頁或文件中擷取文字。**

看到圖片中想要複製的文字？不必再手動輸入。截取螢幕畫面後，Quick SnapOCR 會自動辨識擷取區域內的文字內容，並將結果直接複製到剪貼簿。無論是 PDF 截圖、網頁圖片還是影片字幕，提取文字輕而易舉。

## <img src="./docs/public/images/quick-logo/Quick SnapTranslate.svg" width="64" align="left" style="margin-right: 16px;" /> Quick SnapTranslate

**截圖、辨識、翻譯一氣呵成——跨語言工作毫不費力。**

在圖片、文件或網頁中遇到外文？Quick SnapTranslate 讓你截取螢幕畫面，自動辨識文字並翻譯成你偏好的語言——只需一個動作即可完成。同時支援線上 OCR（騰訊雲 API）與離線 OCR（PaddleOCR），兼顧速度與隱私，還內建釘圖功能方便隨時參考。

## <img src="./docs/public/images/quick-logo/Quick Windowinspector.svg" width="64" align="left" style="margin-right: 16px;" /> Quick WindowInspector

**擷取任何視窗的詳細資訊——比 Spy++ 更簡單直覺。**

將滑鼠懸停在任何視窗上，即可即時檢視其控制代碼（Handle）、PID、標題、客戶端區域尺寸、裝置像素比（DPR）、應用程式路徑等資訊。目標視窗會自動以可自訂的邊框高亮顯示，全域快速鍵可立即啟動。軟體開發、UI 自動化測試與系統管理的不可或缺工具。

## <img src="./docs/public/images/quick-logo/Quick AlwaysOnTop.svg" width="64" align="left" style="margin-right: 16px;" /> Quick AlwaysOnTop

## <img src="./docs/public/images/quick-logo/Quick DefenderToggle.svg" width="64" align="left" style="margin-right: 16px;" /> Quick DefenderToggle

**快速啟用或停用 Windows Defender——進階使用者的全面掌控工具。**

無需深入群組原則編輯器或登錄檔——三種控制模式（STOP / START / FORCE ENABLE）讓你一鍵管理 Microsoft Defender 防毒軟體。即時狀態回饋與詳細操作日誌，讓你隨時掌握每一步。採用標準群組原則機制，安全可靠。

> 需要以系統管理員身分執行。停用 Defender 會降低系統安全性——請僅在必要時使用，並在完成後及時重新啟用防護。
